# Daily Scrum Log (individual)

Nothing is pre-filled: every entry must describe what **you** actually did that day. Do not write entries for days that have passed without records. Sprint 1: 17-22 Oct 2026. Sprint 2: 23-30 Oct 2026.

How to keep it honest: fill it in at the start and end of each work session, take timestamps from your Git commits/Jira, and keep screenshots of Jira or commit pages as proof.

## Entry template (copy for each day)
```
### YYYY-MM-DD  (Sprint N, day X)
Time spent: __ h            Jira issues touched: PVS-__

Yesterday I completed (facts only):
-
Today I plan to do (PLANNED - written at start of day):
-
Blockers / risks:
-
End-of-day self-review (COMPLETED - written at end of day):
- Done:
- Not done and why:
- Evidence (commit hash / test run / Jira link):
- What I will change tomorrow:
```
